## Logo Guidelines:

The EagleSearch logo should:
- Feature an eagle symbol representing vision, speed, and freedom
- Use the primary brand color: #FF6B00 (Orange)
- Be available in both SVG (for web) and PNG (for fallback) formats
- Work on both light and dark backgrounds
